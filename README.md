# SolidBooth · Web-Demo

Statische, **simulierte** Vorführversion der SolidBooth-Oberfläche (Einrichtung, Kiosk, Handyansicht).
Keine Kamera, keine Anmeldung, keine echten Event- oder Gästedaten. Fotos aus der optionalen Webcam bleiben im Browser.

Automatisch erzeugt mit `node dev/build-web-demo.cjs` aus dem SolidBooth-Quellcode. Nicht von Hand bearbeiten.

Drittanbieter: Font Awesome 4.7 (SIL OFL 1.1 / MIT, siehe `pb/`), QR Code Generator von Kazuhiko Arase (MIT, `demo/qrcode.js`).
